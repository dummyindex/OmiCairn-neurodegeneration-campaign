# OmiCairn neurodegeneration research campaign

> **Early-stage research release.** Everything in this repository was generated by an autonomous AI analysis system. The reports are hypothesis-generating. They have not been peer reviewed and have not been checked by human experts. Do not use them as established findings or for clinical decisions.

## What this is

This repository holds the outputs of 57 research runs of OmiCairn, an autonomous multi-agent analysis system. The runs were launched on open Parkinson's disease (PD), Alzheimer's disease (AD) and cross-disease datasets covering single-cell, spatial, genetic and proteomic data. It is released with the OmiCairn manuscript (in preparation) as:

1. **A hypothesis-level outcome table for the community.** Every hypothesis the campaign nominated is listed with its adjudicated verdict and supporting evidence, in [`HYPOTHESES.md`](HYPOTHESES.md) (readable) and [`data/hypotheses.csv`](data/hypotheses.csv) (machine-readable). Most of these outcomes are null, negative or untestable, and they are released deliberately so that others can avoid repeating the same analyses.
2. **The final generated report of each run that produced one** (23 runs), in [`reports/`](reports/).

No run stopped before planning because data were unavailable. Data limitations appear inside the executed runs, as hypotheses that could not be tested.

## Headline outcomes

The 27 runs that completed at least one test evaluated 136 hypotheses against their pre-registered decision rules:

| Verdict | Hypotheses | Share |
|---|--:|--:|
| Supported | 15 | 11% |
| Partially supported | 7 | 5% |
| Not supported | 45 | 33% |
| Inconclusive | 31 | 23% |
| Not testable (data) | 38 | 28% |
| **Total** | **136** | |

- 83 of the 136 hypotheses (61%) were either not supported or not testable with the available data. Counting every partially supported and inconclusive hypothesis as supported would still give at most 53/136 (39%).
- 11 of the 33 planned runs had at least one fully supported hypothesis.
- The 33 planned runs nominated 179 hypotheses in total (160 pre-registered, 19 proposed on the fly). The remaining 43 are marked *Not tested (run did not execute)* and are excluded from the counts above. 30 of them come from 6 planned runs that never completed a test, and 13 come from runs that tested other hypotheses.

[`HYPOTHESES.md`](HYPOTHESES.md) breaks these counts down by disease and other subsets.

## How verdicts were assigned

Verdicts were assigned by **AI adjudication agents, not by human experts and not through peer review**. For each hypothesis, an agent read the latest artefacts of the run (results, analysis notes, knowledge-graph updates, the written report and any review or claim-audit notes). It then applied the run's own pre-registered decision rule. A later execution stage overrides an earlier one. Every verdict is backed by a verbatim quote from the run outputs, and every quote was machine-checked against its source file (exact match up to whitespace and Markdown formatting). In one quote (`parkinson-plasma-prodromal-panel-r3`, H1) an operating-system name was replaced by the placeholder `[the analysis platform]` during release processing.

The adjudication was deliberately conservative. Proxy or surrogate analyses do not count as tests of the pre-registered hypothesis, and where the data did not meet the rule the verdict follows the data, even if the run's own label or report claimed support. In about 15 cases the verdict is stricter than the run's own label; `adjudication_note` explains each one. Full details are in [`HYPOTHESES.md`](HYPOTHESES.md).

## Limitations

- **AI-generated and hypothesis-generating.** Each report was written end to end by OmiCairn without manual edits to its scientific content. None has been peer reviewed. During release review, many reports were found to contain unresolved internal inconsistencies, such as figure and caption mismatches, counts that differ between sections, titles stronger than the results, and citation metadata that needs checking. These were recorded but not corrected, because correcting them would mean rewriting the system's output.
- **Internal review scores come from a simulated reviewer.** The "review" stage in each run is OmiCairn's own simulated manuscript reviewer, which is part of the system. Reaching that stage, or a high score there, shows only that the run passed through the pipeline. It does not show external scientific validity. In the manuscript, two external domain reviewers scored seven campaign manuscripts lower than the internal reviewer did.
- **Most runs halted or produced null or negative results.** These outcomes are reported deliberately and have not been filtered or softened. Many executed analyses are underpowered (for example n = 2 + 2 donors), rely on fallback tissues or surrogate methods, or could not access the intended data. The reports and `adjudication_note` disclose these cases.
- **Input data are public and are not redistributed.** The runs used open resources. Datasets named in the reports include the SEA-AD atlas, CELLxGENE-hosted atlases (such as the Fullard et al. 2024 multi-region PD atlas), GEO series (for example GSE138852, GSE147528, GSE157783, GSE157827, GSE167335, GSE174367, GSE178265, GSE184950, GSE193688, GSE223138, GSE303823), PRIDE PXD030142 and PXD046355, published PPMI supplement tables, LINCS L1000, GWAS summary statistics and the GWAS Catalog, 1000 Genomes allele frequencies, CellChatDB, Recon3D and the Allen Human Brain Atlas. Each report lists its exact accessions. Controlled-access data (for example dbGaP) were not accessed, and the reports record where this blocked a test.
- **Only minimal traces are released.** This repository contains the final reports and the hypothesis-level outcomes. It does not include agent transcripts, analysis code, intermediate results or knowledge graphs. Reports sometimes mention run-internal files (for example `results.json` or stage code directories); those files are not shipped. The full system is available at <https://github.com/dummyindex/OmiCairn>.
- **Release processing.** Before release, run identifiers were renumbered and run dates and times were removed, and the reports were scrubbed of local file paths, machine and environment names, engine-internal notes and obsolete internal system names. Missing figure files were added to the Markdown reports, and the LaTeX reports were recompiled. One figure panel that displayed a local path and an authentication message was re-rendered from the run's own plotting script, with the status text neutralised (`parkinson-foundation-embedding`, Fig. 4b), and one schematic figure was cropped to remove blank space (`alzheimer-apoe4-microglia-ldam`, Fig. 1). No numbers, statistics, verdicts, hypotheses, figure data or citations were changed.
